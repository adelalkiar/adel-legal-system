# نظام العادل للخدمات القانونية
### برمجة: عادل العراقي

نظام متكامل لإصدار فواتير وخدمات قانونية، مبني بـ Node.js / Express وقاعدة بيانات SQLite، مع نظام تفعيل بمفاتيح سداسية عشرية (Hex) تُدار من لوحة تحكم سرية خاصة بالمبرمج.

---

## 1) متطلبات التشغيل
- Node.js نسخة 18 أو أحدث.

## 2) التشغيل المباشر (بدون كتابة أوامر) — الطريقة الموصى بها

بداخل مجلد البرنامج ملف تشغيل جاهز حسب نظام جهازك، فقط **اضغط عليه ضغطتين**:

| نظام التشغيل | الملف |
|---|---|
| Windows | `تشغيل_البرنامج.bat` |
| macOS | `تشغيل_البرنامج.command` |
| Linux | `تشغيل_البرنامج.sh` |

سيقوم الملف تلقائيًا بتجهيز البرنامج عند أول مرة (يتطلب اتصال إنترنت لمرة واحدة فقط)، ثم تشغيل الخادم وفتح البرنامج في متصفحك مباشرة. **يشترط أن يكون Node.js مثبتًا مسبقًا على الجهاز** — إن لم يكن مثبتًا سيظهر لك رابط تحميله تلقائيًا.

> على أنظمة macOS و Linux قد تحتاج أول مرة فقط لمنح الملف صلاحية تشغيل عبر الأمر: `chmod +x تشغيل_البرنامج.command`

## 2ب) التشغيل اليدوي عبر الطرفية (اختياري، لمن يفضل ذلك)

```bash
cd adel-legal-system
npm install
node server.js
```

عند أول تشغيل يتم إنشاء قاعدة البيانات `db/adel.db` تلقائيًا، وستظهر رسالة في الطرفية تحتوي:
- رابط البرنامج للمستخدم: `http://localhost:3000`
- **رابط لوحة التحكم السرية** الخاصة بك (لا تتم مشاركته مع المستخدمين).

## 3) كلمة مرور لوحة التحكم

كلمة المرور الافتراضية عند أول تشغيل هي: `Adel07800780`

يمكنك تغييرها لاحقًا من داخل لوحة التحكم نفسها (قسم "تغيير كلمة مرور لوحة التحكم")، أو عند أول تشغيل عبر متغير بيئة:

```bash
ADEL_ADMIN_PASSWORD="كلمة_مرور_جديدة" node server.js
```//(فقط في أول تشغيل قبل إنشاء قاعدة البيانات)

⚠️ **مهم:** مسار لوحة التحكم (الجزء بعد `/` في الرابط) يتولّد عشوائيًا ويُطبع في الطرفية عند التشغيل. احتفظ به في مكان آمن. لتغييره يدويًا، عدّل قيمة `panel_slug` مباشرة في جدول `admin_settings` بقاعدة البيانات.

## 4) عمل مفتاح تفعيل لعميل جديد

1. ادخل إلى رابط لوحة التحكم السرية.
2. سجّل الدخول بكلمة المرور.
3. من قسم "توليد مفتاح تفعيل جديد" اختر المدة (أيام محددة / أسبوع / شهر / سنة / مؤبد) وعدد المفاتيح المطلوب، ثم اضغط "توليد المفتاح".
4. انسخ المفتاح وسلّمه للعميل ليدخله في شاشة تفعيل البرنامج.

## 5) إيقاف تفعيل عميل في أي وقت

من نفس اللوحة، قسم "جميع مفاتيح التفعيل"، اضغط زر **"إيقاف"** أمام المفتاح المطلوب. يتوقف عمل البرنامج لدى المستخدم خلال 5 دقائق كحد أقصى (فترة التحقق الدوري)، أو فورًا عند إعادة تحميل الصفحة لديه.

## 6) استخدام البرنامج (طرف المستخدم المفعَّل)

- **فاتورة جديدة:** تعبئة بيانات العميل والخدمات، رقم الفاتورة والتاريخ يُعبّآن تلقائيًا ويمكن تعديلهما.
- **قفل/فتح تحرير النصوص الثابتة:** زر أعلى يمين ورقة الفاتورة (العناوين والملاحظات الثابتة)، اضغط لفتح القفل والتعديل، واضغط مجددًا للحفظ وإعادة القفل.
- **الحقول القابلة للتحويل إلى قائمة:** بجانب حقول مثل "موضوع التكليف" و"المحكمة/الجهة" و"طريقة الدفع" زر (+) لإضافة عنصر جديد للقائمة، ورابط لتبديل الحقل بين "إدخال حر" و"اختيار من قائمة".
- **المحامي المسؤول:** حقل اختيار من متعدد بشكل دائم، أضف الأسماء عبر زر (+) بجانبه أو من تبويب "إدارة المحامين والقوائم".
- **إعدادات الشركة:** من التبويب المخصص، أدخل اسم الشركة (عربي/إنجليزي)، الوصف، بيانات التواصل، وارفع الشعار — تنعكس تلقائيًا على كل الفواتير.
- **سجل الفواتير:** استعراض، فتح للتعديل، أو حذف أي فاتورة سابقة.
- **الطباعة:** زر "طباعة" أعلى الصفحة يطبع ورقة الفاتورة فقط (بدون شريط الأدوات والتبويبات).

## 7) هيكل المشروع

```
adel-legal-system/
├── server.js              نقطة تشغيل الخادم
├── db/database.js         تعريف قاعدة البيانات والبيانات الافتراضية
├── middleware/             حماية الجلسات ومفاتيح التفعيل
├── routes/                 مسارات API (تفعيل، أدمن، فواتير، شركة، حقول، نصوص)
└── public/                 واجهات المستخدم (index.html للمستخدم، admin/admin.html للوحة السرية)
```

## 8) ملاحظة أمنية
- كلمات المرور مشفّرة (bcrypt) ولا تُخزَّن كنص صريح.
- كل طلبات لوحة التحكم محمية بجلسة (Session) منفصلة عن نظام التفعيل.
- يوجد حد لمحاولات تسجيل الدخول الفاشلة المتكررة على لوحة التحكم (قفل مؤقت 10 دقائق بعد 6 محاولات).
- يُنصح بتشغيل البرنامج خلف HTTPS عند النشر الفعلي على الإنترنت، وبتغيير كلمة المرور الافتراضية فورًا.
